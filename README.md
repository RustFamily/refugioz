# RefúgioZ Launcher Distribution

Este repositório armazena os arquivos remotos consumidos pelo launcher RefúgioZ:

- `mods-list.json`
- `anticheat.json`
- `launcher-update.json`
- `launcher/RefúgioZ.exe`
- `launcher/RefúgioZ_Update.exe`
- `launcher/checksums.json`

## Importante

No estado atual o repositório está privado. URLs RAW privadas do GitHub não funcionam para jogadores sem autenticação.

Para distribuição pública segura, use uma destas opções:

- GitHub Releases públicas
- repositório público dedicado apenas à distribuição
- servidor/CDN próprio
- proxy/API controlado pelo dono

Não embuta token GitHub no launcher.
